
# Конфигурация виртуальной машины `devops-vm`

## 1. Параметры машины

- **Операционная система:** Ubuntu 22.04.5 LTS.
- **Оперативная память:** 2 ГиБ.
- **Количество виртуальных процессоров:** 2.
- **Размер виртуального диска:** 25 ГБ.
- **Размер корневого логического тома:** 11,5 ГБ.
- **Архитектура:** x86-64.
- **Гипервизор:** Oracle VirtualBox.

## 2. Сетевые интерфейсы

- **`enp0s3`** — интерфейс NAT с IP-адресом `10.0.2.15/24`. Шлюз по умолчанию: `10.0.2.2`.
- **`enp0s8`** — интерфейс Host-only с IP-адресом `192.168.79.101/24`.
- **`lo`** — локальный интерфейс с IP-адресом `127.0.0.1`.

## 3. Правила проброса портов

Настроен проброс TCP-соединений с хостовой системы на SSH-службу виртуальной машины.

- **Windows:** `127.0.0.1:2222` → `2222` гостевой системы.
- **Mac:** `192.168.1.72:2223` → `2222` гостевой системы.

SSH-служба внутри виртуальной машины использует порт `2222`.

## 4. Учётные записи

- **Пользователь:** `devops`.
- **UID:** `1001`.
- **Основная группа:** `devops` (GID `1001`).
- **Дополнительная группа:** `sudo`.
- **Способ удалённой аутентификации:** SSH по публичным ключам.
- **Парольная аутентификация по SSH:** отключена.
- **Вход пользователя `root` по SSH:** запрещён.

## 5. Служба SSH

- **Порт:** `2222`.
- **Файл конфигурации:** `/etc/ssh/sshd_config`.
- **Разрешённые пользователи:** `devops`.
- **`PermitRootLogin`:** `no`.
- **`PasswordAuthentication`:** `no`.
- **`MaxAuthTries`:** `3`.
- **Способ аутентификации:** SSH-ключи.

## 6. Правила межсетевого экрана

Используется UFW. Межсетевой экран активен.

Политики по умолчанию:
- Входящие соединения: `deny`.
- Исходящие соединения: `allow`.
- Маршрутизируемые соединения: `disabled`.

Правила:
- `80/tcp` — HTTP, разрешён.
- `443/tcp` — HTTPS, разрешён.
- `2222/tcp` — SSH, ограничение частоты подключений (`LIMIT`).

Правила настроены для IPv4 и IPv6.

## 7. Снимки состояния

Указать фактически созданные снимки виртуальной машины, их названия и даты создания. Информацию проверить в менеджере снимков VirtualBox.

## 8. Веб-сервер

- **Пакет:** Nginx (`nginx`), версия 1.18.0.
- **Конфигурация ресурса:** `/etc/nginx/sites-available/devops-site`.
- **Активная конфигурация:** `/etc/nginx/sites-enabled/devops-site`.
- **Каталог ресурса:** `/var/www/devops-site`.
- **Владелец каталога и файлов:** `devops:devops`.
- **Права каталогов:** `755` (`drwxr-xr-x`).
- **Права HTML-файлов:** `644` (`-rw-r--r--`).
- **Сертификат:** `/etc/ssl/certs/devops.crt`, владелец `root:root`, права `644`.
- **Закрытый ключ:** `/etc/ssl/private/devops.key`, владелец `root:root`, права `600`.
- **Срок действия сертификата:** 365 дней, с 21 октября 2026 года по 21 октября 2027 года.

### Формирование сертификата

```bash
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/devops.key \
  -out /etc/ssl/certs/devops.crt \
  -subj "/CN=devops.local" \
  -addext "subjectAltName=DNS:devops.local"
```

Сертификат самоподписанный. Поле Subject Alternative Name содержит DNS-имя `devops.local`.
